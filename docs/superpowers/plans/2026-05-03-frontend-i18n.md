# Frontend Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add i18n to the React frontend supporting English and Simplified Chinese using react-i18next.

**Architecture:** Install `react-i18next` and `i18next`. Create an `i18n/` directory with `index.ts` (init config), `en.json` (English base), and `zh.json` (Simplified Chinese). Import i18n init in `main.tsx`. Add a language toggle to the sidebar. Then systematically replace hardcoded strings in every page, component, and hook with `t('key')` calls.

**Tech Stack:** React 18, react-i18next, i18next, TypeScript, Vite

- [ ] **Step 4: Create `web/src/i18n/index.ts`**

```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import en from './en.json';
import zh from './zh.json';

const savedLanguage = localStorage.getItem('i18n-language');

i18n.use(initReactI18next).init({
  resources: {
    en: { translation: en },
    zh: { translation: zh },
  },
  lng: savedLanguage || (navigator.language.startsWith('zh') ? 'zh' : 'en'),
  fallbackLng: 'en',
  supportedLngs: ['en', 'zh'],
  interpolation: {
    escapeValue: false,
  },
});

export default i18n;
```

- [ ] **Step 2: Update each hook file**

For each hook file, add `import { useTranslation } from 'react-i18next';` and replace toast strings.

**IMPORTANT:** Hooks are not React components — `useTranslation()` can only be used inside components. Since these hooks use `useMutation`, the `onSuccess`/`onError` callbacks run after the mutation. There are two options:

**Option A (recommended):** Import `i18n` directly and use `i18n.t()`:

```typescript
import i18n from '../i18n';
// ...
toast.success(i18n.t('toasts.keyCreated'));
toast.error(getErrorMessage(err, i18n.t('toasts.keyCreateFailed')));
```

This works because `i18n.t()` reads the current language without needing React context.
