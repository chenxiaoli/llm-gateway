# Usage Statistics

## View Usage

Go to the **Usage** page to see your API usage.

## Filters

- Time range: last 7 days / 30 days
- Group by day to see daily token consumption

## Data Fields

- **Input Tokens**: tokens consumed by your requests
- **Output Tokens**: tokens consumed by model responses
- **Cache Tokens**: tokens from context caching (lower price)
- **Weighted Tokens**: normalized total token count
