# Channel Configuration

## Add a Channel

In the admin panel, go to the **Channels** page and click **Add Channel**.

## Channel Parameters

- **Name**: channel identifier
- **Provider**: associated upstream provider
- **Priority**: lower number = higher priority
- **Weight**: selection weight among channels with the same priority
- **Available Hours**: restrict channel availability by time

## Test a Channel

Click the **Test** button on the right side of the channel row to send a test request and verify the configuration.
